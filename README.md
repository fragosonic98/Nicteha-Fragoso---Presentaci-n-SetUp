## 🎯 Objetivos técnicos · Próximos 3 meses

### 01 · Seguridad en aplicaciones web y APIs

Identificar y mitigar las vulnerabilidades más comunes en aplicaciones web (OWASP Top 10), con énfasis en APIs REST construidas con Java y Node.js. Al término del periodo, seré capaz de auditar mis propias APIs y documentar los hallazgos con un criterio técnico estructurado.

---

### 02 · Seguridad en entornos cloud (Azure)

Comprender los principios de seguridad aplicados a arquitecturas cloud, particularmente en Azure: gestión de identidades (IAM), control de accesos, cifrado en tránsito y en reposo, y buenas prácticas para microservicios. El objetivo es aplicar estos principios en los proyectos que desarrollo actualmente en mi entorno laboral.

---

### 03 · Análisis de datos aplicado a la detección de anomalías

Utilizar técnicas de análisis de datos para identificar patrones de comportamiento inusual en logs y tráfico de red. Esto conecta el componente de análisis de datos del bootcamp con una aplicación directa en ciberseguridad, reforzando mi perfil técnico en una intersección cada vez más relevante en la industria.
